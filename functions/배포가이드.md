# TrainLog 자동 리포트 — Firebase Cloud Functions 배포 가이드

완료하면 매일 자동으로 이메일이 도착해:
- **21:00** → 훈련 로그 요약
- **09:00** → 전날 컨디션 체크 요약

---

## 1단계 — Node.js 설치 확인

터미널을 열고:
```bash
node --version   # v18 이상 필요
npm --version
```

없으면 https://nodejs.org 에서 LTS 버전 설치.

---

## 2단계 — Firebase CLI 설치

```bash
npm install -g firebase-tools
```

---

## 3단계 — Firebase 로그인

```bash
firebase login
```

브라우저가 열리면 `jaemyung1287@gmail.com` 으로 로그인.

---

## 4단계 — 프로젝트 연결

TrainLog 앱 폴더로 이동 후:
```bash
cd "Athlete Training Log App"
firebase use traininglogskeleton
```

---

## 5단계 — Gmail App Password 발급

Firebase Functions이 Gmail로 이메일을 보낼 때 필요한 비밀번호야.

1. https://myaccount.google.com/apppasswords 접속
2. 앱 선택: **기타 (직접 입력)** → 이름: `TrainLog Bot`
3. **생성** 클릭 → 16자리 비밀번호 복사 (예: `abcd efgh ijkl mnop`)

---

## 6단계 — App Password를 Firebase Secret으로 저장

```bash
firebase functions:secrets:set GMAIL_APP_PASSWORD
```

프롬프트에 위에서 복사한 16자리 비밀번호 붙여넣기 (공백 제거하고 입력).

---

## 7단계 — 패키지 설치

```bash
cd functions
npm install
cd ..
```

---

## 8단계 — 배포

```bash
firebase deploy --only functions
```

성공하면 이런 메시지가 나와:
```
✔ functions[eveningTrainingReport]: Successful create operation.
✔ functions[morningConditionReport]: Successful create operation.
```

---

## 배포 후 확인

Firebase Console에서 확인:
https://console.firebase.google.com/project/traininglogskeleton/functions

**수동 테스트** (바로 이메일 받고 싶을 때):
```bash
firebase functions:shell
# 쉘 진입 후:
eveningTrainingReport()
morningConditionReport()
```

## 문제 해결

**이메일이 안 와요**
```bash
firebase functions:log --only eveningTrainingReport
```
로그에서 오류 확인.

**App Password 오류가 나요**
- Gmail 계정에 2단계 인증이 활성화되어 있어야 App Password 발급 가능
- https://myaccount.google.com/security 에서 확인

**함수 수정 후 재배포**
```bash
firebase deploy --only functions
```
